## 🚀 Featured Projects

### Predictive ML-Driven DDoS Defence for SDN-Enabled ICS
A Python-based simulation framework for evaluating machine learning models against DDoS attacks in Software-Defined Networking (SDN) environments.

**Technologies:** `Python`, `Scikit-learn`, `NumPy`, `Pandas`

**What it demonstrates:**
- Implementation of predictive ML models for network security
- Simulation of DDoS attacks on Industrial Control Systems
- Analysis of SDN controller responses and system performance

### Stock Market Price Prediction
A web application designed for predicting stock market prices using an Artificial Neural Network (ANN) trained on live financial data.

**Technologies:** `Python`, `PyTorch`, `FastAPI`, `JavaScript`, `Chart.js`

**What it demonstrates:**
- Training and deploying an ANN model for time-series forecasting
- Real-time data fetching using yfinance
- Serving predictions via robust REST APIs

### PDF Copilot — RAG Document Chatbot
An intelligent chatbot leveraging Retrieval-Augmented Generation (RAG) to synthesize answers directly from uploaded PDF documents.

**Technologies:** `Python`, `FastAPI`, `Google Gemini`, `Hugging Face Embeddings`

**What it demonstrates:**
- Building end-to-end RAG pipelines for document querying
- Integrating Large Language Models (LLMs) with semantic search
- Delivering natural language answers backed by factual context

### ContextBridge
An AI conversation workspace designed to maintain context continuity seamlessly across multiple AI models.

**Technologies:** `Generative AI`, `LLMs`, `Prompt Engineering`

**What it demonstrates:**
- Automatic generation of portable context summaries
- Transitioning of facts and user goals between different AI models (e.g., Qwen and Gemini)
- Advanced context management for complex AI interactions

### Devlingo
A gamified developer learning platform providing structured skill roadmaps and interactive coding challenges.

**Technologies:** `React`, `TypeScript`, `Supabase`, `Tailwind CSS`

**What it demonstrates:**
- Full-stack web application development
- Interactive educational tools and user-focused design

### ReTicket
A verified ticket exchange platform for secure event ticket transactions.

**Technologies:** `React`, `TypeScript`, `NestJS`, `PostgreSQL`, `Redis`

**What it demonstrates:**
